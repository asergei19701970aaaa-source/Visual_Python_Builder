# Готовые проекты для изучения

Эта папка содержит два типа файлов:

- **технические проверки** с ранними номерами. Они нужны для автоматической проверки совместимости;
- **готовые учебные проекты** с номером 20 и выше. Они показывают законченную задачу, а не отдельную ноду.

## Новые проекты

- `02_калькулятор_заказа.json`: форма с двумя полями, кнопкой, вычислением и понятным результатом.
- `20_список_покупок.json`: ввод товара, добавление в список и показ выбранного товара.
- `21_таймер_фокуса.json`: запуск и остановка таймера, счётчик, вычисление и видимый статус.
- `22_тетрис_на_малых_нодах.json`: полный тетрис, собранный из маленьких общих нод. Специальной ноды «Тетрис» в нём нет.

Каждый проект можно открыть, запустить и менять. Начните с подписей и свойств, затем проследите линии от действия человека к видимому результату.

## Тетрис на малых нодах (проект 22)

### Как играть

| Клавиша | Действие |
|---|---|
| ← или A | сдвиг влево |
| → или D | сдвиг вправо |
| ↑ или W | поворот (у стены фигура сама отступает на клетку) |
| ↓ или S | на клетку вниз |
| Пробел или X | сбросить фигуру до дна |
| P | пауза и продолжение |
| R | новая игра |

Если вы изменили число в настройках, стрелки могут менять это число. Тогда управляйте клавишами A, D, W, S.

### Настройки на экране

| Настройка | Что меняет | Когда действует |
|---|---|---|
| Ширина поля, Высота поля | размер стакана | при новой игре (R) |
| Мусорных строк при старте | нижние строки заполнены блоками с дырками | при новой игре (R) |
| Начальный уровень | с какого уровня начать | сразу |
| Скорость: шаг вниз на 1 уровне, мс | как часто фигура падает на клетку. Меньше число — быстрее | со следующей фигуры |
| Ускорение за уровень, мс | на сколько быстрее каждый новый уровень | со следующей фигуры |
| Самый быстрый шаг, мс | предел скорости | со следующей фигуры |
| Линий до нового уровня | сколько линий убрать для нового уровня | сразу |
| Очки за клетку быстрого сброса | бонус за Пробел | сразу |
| Набор фигур | классические 7, лёгкие 5, расширенные 12, только палки и квадраты | со следующей фигуры |
| Цвета | Классика, Неон, Пастель, Монохром | сразу |
| Показывать тень | серый контур там, куда упадёт фигура | сразу |

### Настройки в свойствах нод (для смелых)

- **Своя фигура.** Выберите ноду `f_set` («Выбор из четырёх вариантов»). В свойствах `option_0`…`option_3` записаны наборы фигур. Формат: `Имя/цвет: x,y; x,y; x,y`. Фигуры разделяет черта `|`. Пример: `Уголок/13: 0,0; 0,1; 1,1`. Номер цвета берётся из палитры.
- **Свои цвета.** Нода `f_palette`: каждый вариант — словарь «номер → цвет». Номер 8 — мусорные блоки, 9 — тень.
- **Свои клавиши.** Нода `f_cmd` («Клавиша → команда»): клавиши для каждой команды через запятую. Новые клавиши добавьте также в свойство «Разрешённые клавиши» ноды `kb` («Клавиатура»).
- **Очки за линии.** Нода `f_gain` («Очки за ход»), свойство `table`: очки за 0, 1, 2, 3, 4 линии через запятую. Очки умножаются на уровень.

### Как это устроено

1. **Память.** `m_board` хранит поле с упавшими фигурами. `m_shape` и `m_next` хранят номер текущей и следующей фигуры. `m_score`, `m_lines` хранят счёт и линии.
2. **Положение фигуры** не хранится одним числом. Его считают счётчики: `c_fall` (шаги вниз), `c_left` и `c_right` (шаги в стороны), `c_rot` (повороты). При новой фигуре все счётчики сбрасываются.
3. **Проверка хода.** Перед каждым ходом нода «Помещается на поле?» проверяет новое место. Ответ «да» — счётчик делает шаг. Ответ «нет» — ход отменяется.
4. **Падение.** Таймер каждые N мс пробует шаг вниз. Если шаг невозможен, запускается последовательность `seq_lock`: фигура впечатывается в поле, полные строки убираются, растут счёт и линии. Потом появляется новая фигура.
5. **Конец игры.** Если новая фигура не помещается, шлюзы событий закрываются, таймер останавливается и показывается надпись.
6. **Экран.** Хаб `hub_redraw` после каждого хода перерисовывает поле, следующую фигуру и счёт.

В проекте все общие ноды: Память, Счётчик, Таймер, Клавиатура, Условие, Хаб событий, Шлюз событий, Последовательность, Холст двумерного поля и маленькие ноды из группы «19. Клеточные поля: правила». Эти ноды подходят и для других игр на клетках.
